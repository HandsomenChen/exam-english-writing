# 底稿、校验与 PDF

## 可检查的底稿

一个批次用 JSON 或等价结构保存每题的题面、材料、出处、范文和译解。使用附带的检查脚本时采用以下约定。

- 顶层 `items` 为列表。每题具备唯一 `id`、`track`（`E1A`、`E1B`、`E2A`、`E2B`）、`title`、`prompt`、`analysis`、`expressions`、`advanced_zh`、`structure`、`self_check`、`source`。`expressions` 可以是三条释义与例句组成的列表。题面所附的来信、路线说明和素材同样存入底稿。
- `models.basic` 和 `models.advanced` 各含英文 `body`。小作文可以另有 `opening` 和 `closing`，分别存称呼或标题、结束语和署名。`body` 只保存需计入正文的段落。
- 若用图表，`charts` 为列表。每图包含 `title`、`unit`、`scope`（统计对象和分母）、`mode`、`labels`、`series` 和 `simulated`。`mode` 取 `single-share`、`multi-share` 或 `values`，前两者的 `unit` 使用 `%`。`series` 的每项含 `name` 和数值列表 `values`，各列表与 `labels` 对齐。同一组选项互斥且穷尽时用 `single-share`，并核对各组占比和约为 100%。两项可同时发生（如选小份餐与有剩餐）用 `multi-share`。普通数量用 `values`。
- 漫画材料保存画面涉及的动作、文字、素材文件及阅读顺序。实际出 PDF 时提供完整插图。

在命令行从 skill 目录运行 `python3 scripts/check_workbook.py batch.json`。四类各四题的任务加 `--per-track 4`。脚本报告正文与全文词数，并检查基础结构和图表数字。大作文默认用 175–185 词作“约 180”的批量检查窗口，可通过 `--large-min`、`--large-max` 调整。小作文默认校验 100–120 词正文。题意、因果、数据与表述是否一致，仍需人工或模型复核。

## 排版与验收

已认可的 16 题案例为英一小作文、英一大作文、英二小作文、英二大作文各一册，每册四题、八页。结构可随用户要求调整。

- 每题第一页为完整题面、审题拆解、推荐搭配和出处。按实际题目插入来信、附加材料、漫画、图表或表格。来源链接放在分析资料处。
- 每题第二页为扎实版、进阶版、进阶版中文译文、结构梳理与自写提醒。小作文标正文词数，大作文标全文词数。适当增减段间距，保证末段、落款和译文完整。
- 合集用连续页码和题目书签；沿用本项目署名“小红书：gpt学英语”，用户另指定时替换。四册可一起打包。
- 导出后按题查看渲染页，核对题面、范文版本、词数标记、插图、图例、标签和页码。抽查或提取全文验证末段与落款均存在。校验压缩包中的 PDF 与最终发布版本一致。
